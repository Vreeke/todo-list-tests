# TodoMVC — Модульні та інтеграційні тести (Лабораторна робота № 5)

Проєкт містить бізнес-логіку управління списком завдань (валідація, фільтрація, підрахунок активних завдань, синхронізація із сервером) та набір тестів на Jest (3 модульні та 2 інтеграційні тести).

## Запуск
```bash
npm install
npm test
```

CI pipeline enabled via GitHub Actions.
